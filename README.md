# Receipt Splitter

Android app to split restaurant bills among friends. No more "you had the steak" arguments.

## Features
- Add people and assign items to who ate what
- Calculate split with tax and tip
- Split evenly (total ÷ people)
- Share results via SMS/email
- Works completely offline
- No ads, no tracking

## Download
Get the APK from releases or build yourself.

## Build
./gradlew assembleDebug
